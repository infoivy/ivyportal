Goal: make the portal the second brain of the business, runnable by three founders — Abu Bilal (sales), Faizan (student success), Sair (marketing/content/strategy, face of company).

## A. Fix first — migration leftovers (blocking daily use)

1. **Payment links are gone.** Closer Resources says "No payment links yet. Ask an admin to seed them." The 13 Whop links + Wise USD/EUR + Revolut details need re-seeding (all values are in the repo history / earlier docs).
2. **Knowledge Hub lost its docs.** Only "ISA Setting Process" survived. Missing: GA Roadmap, Appointment Setting — Conversational Flexibility, Objection Handling Parts 1+2. Founder Hub SOPs need verifying too.
3. **Setter commission label is still wrong.** Revenue → per-setter breakdown still reads "3.0% BASE · +2.0% PIF BONUS". There is NO setter PIF bonus. Correct model: base + top-setter-every-14-days +1% + $7,500-week +1%. The bonus logic itself needs implementing, not just the label.
4. **Founder Hub weekly plan shows "Loading weeks…"** on an empty database — needs a proper "Generate this cycle" empty state.
5. **Training page is placeholder content.** All 8 "videos" (18:24 ISA Team Welcome etc.) are dummies with no real video behind them. Either wire real recordings or reduce to an empty state with "Add training video" so nobody trusts fake content.
6. **Commission rates editor still sits on the Revenue page** — move to Admin settings as planned.

## B. Team onboarding (this week — Faizan and Abu Bilal are joining)

7. **Invite → role flow.** Today a new signup lands with zero roles and sees nothing. Build a simple flow: Admin → Team → "Invite member" (email + preselected roles + setter type where relevant). When they sign up with that email, roles auto-apply. Otherwise you'll be manually assigning roles in the DB for every setter Abu Bilal onboards.
8. **Role-based landing.** Send each person to their cockpit on login: Abu Bilal → Sales HQ, Faizan → Student Success HQ, setters → My EOD, students → student portal. The generic dashboard should be the founder/admin view only.
9. **First-login checklist per role** (already exists for setters): add closer, CSM, and coach variants. Abu Bilal will onboard people through these — they're his training funnel.

## C. Abu Bilal — Sales HQ (one page that runs his whole job)

10. **Create a "Sales HQ" view** (can be the EOD Team Overview promoted to a page) with everything he needs in order: today's submission status per person → who missed yesterday (with a one-click "Nudge" that copies a pre-written WhatsApp/DM follow-up message) → KPI hit rates this week → setter quality signals (convo→booked %, show rate per setter, flagged data-entry warnings).
11. **Missed-EOD follow-up loop.** Auto-create an action item assigned to Abu Bilal when someone misses an EOD ("Follow up with Ameer — no EOD Thursday"). This is his core job; the portal should hand him the list.
12. **Onboarding tracker for new setters/closers**: pipeline view (Invited → Signed up → SOPs read → First EOD → First set → Ramped) so "onboard new setters" is a visible process, not a memory task.
13. **Setter scorecards**: per-person page with 30-day trends, KPI hit %, conversion quality vs team average — what he opens before a training 1:1.

## D. Faizan — Student Success HQ

15. **Student journey timeline** on each student page: everything in one scroll — onboarding date, calls + ratings, notes, payments, testimonials, status changes. "Where is everyone at" answered in one click.
16. **Progress milestones** per student (defined once in settings, e.g. Onboarded → First appointments → First close → Case study ready) with a progress bar on the student list, so "who has what progress" is scannable.
17. **Testimonial pipeline**: link testimonial requests to student milestones (student hits "first close" → suggested testimonial ask appears for Faizan).
18. **Weekly student digest**: auto-generated Monday summary (new, at-risk, graduated, testimonials collected) — Faizan's Monday briefing, also visible to you.

## E. Sair — Marketing/Content/Strategy
